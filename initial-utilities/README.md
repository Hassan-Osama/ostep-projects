# UNIX Utilities

This project involved building simplified versions of common UNIX utilities in C. The primary goal was to re-familiarize with C programming, file I/O, and the UNIX command-line environment.

## Utilities Implemented

The following utilities were developed as part of this project:

- **[wcat](./wcat)**: A tool to read and print file contents.
- **[wgrep](./wgrep)**: A pattern-matching tool that searches for strings within files.
- **[wzip](./wzip)**: A file compression tool using Run-Length Encoding (RLE).
- **[wunzip](./wunzip)**: A decompression tool to revert files compressed by `wzip`.

Each utility is written in C and follows standard UNIX conventions for command-line arguments and error handling. For more detailed information on each tool, please refer to their respective directories.

### Learning Objectives
* Re-familiarization with the C programming language.
* Understanding UNIX file I/O system calls and library routines.
* Mastering the use of standard UNIX development tools like `gcc` and the command-line interface.
